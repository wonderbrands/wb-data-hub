Nota — cuenta transitoria: "Mercancía Facturada No Enviada" acumula el costo mientras el producto no ha salido físicamente del almacén (OUT pendiente). Al generarse el OUT en Odoo, esta cuenta se cancela contra la cuenta original de inventario, dejando el costo de venta definitivamente registrado.
Problema pendiente de resolución: Debido a que la factura se emite y afecta al Costo de Venta previo a la salida del producto, en algunos casos van a existir distorsiones en el costo promedio del producto vendido. Esto se debe a que un ingreso posterior a la facturación, pero anterior al OUT de dicha orden, modificaría el costo promedio del producto y lo volvería inconsistente con el costo facturado. Pendiente revisión de configuración en Odoo.

Aplicación de cobros

Barrido del reporte ML API para registrar pagos en Odoo

Proceso de aplicación de cobros — Reporte ML API
1
Identificar SOs cobradas en el período

En el reporte de ML vía API, el campo money_release_date define la fecha en que ML libera el cobro de cada orden.

2
Aplicar cobro por cada factura de venta en Odoo

Toda SO cobrada dispara la aplicación del pago sobre la factura de venta correspondiente en Odoo.

3
Asiento contable de cobro

La aplicación del cobro en Odoo genera automáticamente el asiento pertinente, afectando las siguientes cuentas:

105-001-004 Mercado Libre Crédito
102-002-007 Mercado Pago Débito
